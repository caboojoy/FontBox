# 바이브코딩 개발 폰트 배포본

`개발폰트` 폴더의 폰트 5종을 검토하고, 배포에 걸리는 문제를 고쳐 패키지로 묶은 결과입니다. 원본 폴더의 파일은 고치지 않았습니다.

## 패키지

| 패키지 | 글꼴 | 파일 | 한글 |
|---|---|---|---|
| `Cheonui-2.1.zip` (16.1MB) | 천의체, 천의체 장식 | TTF 4개 + WOFF2 4개 | 11,172자 |
| `Suyeom-1.0.zip` (4.7MB) | 수염체 붓털, 수염체 콧수염 | OTF 2개 + WOFF2 2개 | 2,350자 |
| `MungtukMarker-1.0.zip` (8.1MB) | 뭉툭마커 | TTF + WOFF2 | 11,172자 |
| `HwangyaWestern-1.0.zip` (15.5MB) | 황야웨스턴 | TTF + WOFF2 | 11,172자 |

각 패키지에는 폰트, 웹폰트, `OFL.txt`, `README.md`(사용 안내), 견본 이미지, `소스/`(생성 스크립트)가 들어 있습니다.

## 고친 것

| 문제 | 해당 글꼴 | 영향 | 조치 |
|---|---|---|---|
| Regular 스타일 비트가 꺼져 있음 | 수염체 2종, 뭉툭마커, 황야웨스턴 | 윈도우·오피스에서 굵기 연결이 어긋날 수 있음 | `fsSelection`에 Regular 비트 설정 |
| 줄 높이 값이 표마다 다름 | 수염체 2종, 뭉툭마커, 황야웨스턴 | 윈도우·맥·웹에서 줄 간격이 다르게 나옴 | hhea와 win을 맞추고 typo 줄 간격을 0으로 |
| 글자가 줄 높이 밖으로 나감 | 수염체 2종 | 세로선(`\|`) 아래쪽이 윈도우에서 잘림 | win 하강 값을 250에서 286으로 |
| 밑줄 두께가 0 | 수염체 2종, 뭉툭마커, 황야웨스턴 | 밑줄을 쳐도 보이지 않음 | 위치 -125, 두께 50 |
| 줄바꿈 없는 공백(U+00A0) 없음 | 수염체 2종, 뭉툭마커 | 웹에서 `&nbsp;` 칸만 다른 글꼴로 바뀜 | 공백 글리프에 연결 |
| x높이·대문자 높이가 0 | 수염체 2종 | 일부 프로그램의 크기 맞춤이 어긋남 | 실제 글리프에서 계산 |
| 수정분 저작권자 이름이 비어 있음 ("© 2026.") | 천의체, 천의체 장식 | 저작권 표기가 불완전함 | 폰트 안쪽·`OFL.txt`·소스를 "2026 도겸"으로 통일 |
| 고유 ID의 버전이 다름 (`2.0;` / 버전 2.100) | 천의체, 천의체 장식 | 폰트 캐시가 옛 버전과 혼동할 수 있음 | `2.100;이름`으로 통일 |
| 기능 목록이 태그 순이 아님 | 천의체, 천의체 장식 | 브라우저 검사기(OTS)가 경고 | 태그 순으로 정렬 |
| 쓰이지 않는 이름 레코드, 중복 레코드, `ltag` | 천의체 계열, 뭉툭마커, 황야웨스턴 | 동작에는 영향 없음 | 제거 |
| 글꼴 이름 변경 | 뭉툭마커 | 원본은 '겸손마커(Gyeomson Marker)'로 빌드됨 | 폰트 안쪽 이름·파일 이름·`OFL.txt`·소스를 '뭉툭마커(Mungtuk Marker)'로 변경 |
| 웹폰트(WOFF2) 없음 | 뭉툭마커, 황야웨스턴 | 웹에서 쓸 수 없음 | 생성 |
| 힌팅 없는 TTF에 `gasp` 없음 | 뭉툭마커, 황야웨스턴 | 윈도우 작은 글씨가 거칠게 나올 수 있음 | 모든 크기에서 부드럽게 그리도록 지정 |
| 두 글꼴이 zip 하나에 섞여 있고 안내·소스 없음 | 뭉툭마커, 황야웨스턴 | 바탕 폰트가 달라 저작권 표기가 섞임 | 패키지를 나누고 `OFL.txt`를 글꼴별로 작성 |
| 사용 안내 없음 | 수염체, 뭉툭마커, 황야웨스턴 | | `README.md` 작성 |

원본 폴더의 `font-builder_천의체`와 `CLAUDE_천의체 외.md`는 이름과 달리 뭉툭마커·황야웨스턴 생성기와 그 문서입니다. 배포본에서는 해당 패키지의 `소스/`에 넣었습니다.

## 문제 없음을 확인한 것

- 라이선스: 바탕 폰트 5종(Noto Serif KR, Noto Sans CJK, Noto Serif CJK, Gamja Flower, Rye)이 모두 SIL OFL 1.1입니다. 각 `OFL.txt`의 본문이 OFL 1.1 원문과 일치합니다.
- 예약 이름: 글꼴 이름에 "Source", "Rye"가 들어 있지 않습니다.
- 임베딩 제한 없음(`fsType` 0), 한글 이름과 영문 이름이 모두 들어 있음.
- 빈 글리프 없음, 윤곽 방향 정상(ㅇ·ㅁ 안쪽이 채워지지 않음).
- 천의체: 단어 첫 글자 자동 장식(`calt`), `ss01`·`ss02`·`ss03`, 컬러 팔레트 3종, 천의체 장식의 내장 글리프가 고친 뒤에도 같게 동작합니다.

## 검증

```bash
python 도구/verify.py
```

글꼴 8개와 웹폰트 8개가 모든 항목을 통과했습니다. 브라우저가 쓰는 검사기(OTS)도 경고 없이 통과합니다. 셰이핑은 크롬과 같은 엔진(HarfBuzz)으로 확인했습니다.

확인하지 못한 것:

- 고친 파일을 실제 윈도우·맥에 설치하거나 워드·포토샵에서 열어 보지는 않았습니다.
- 천의체의 SVG 컬러가 포토샵·일러스트레이터에서 컬러로 나오는지는 원본 안내서에도 미확인으로 남아 있습니다.

## 배포 전에 정할 것

1. **글꼴 이름 중복.** '천의체', '수염체', '뭉툭마커', '황야웨스턴'이라는 이름의 기존 폰트나 상표가 있는지는 충분히 확인하지 않았습니다.

황야웨스턴의 Noto Serif CJK 저작권 연도는 "2017-2023"으로 통일했습니다. 빌드에 쓴 리눅스의 Noto 파일을 다시 확인할 수 없어, 윈도우에 설치된 Noto Serif KR 2.02의 표기(© 2017-2023 Adobe)를 따랐습니다.

## 남은 제한 (다시 빌드해야 고칠 수 있음)

- 수염체는 한글 2,350자만 지원합니다.
- 뭉툭마커에는 줄표(–, —)가 없고, '풹' 한 글자가 크게 나옵니다. 바탕인 감자꽃에서 온 것입니다.
- 황야웨스턴은 TTF 13.6MB, WOFF2 7MB입니다. 웹에서는 필요한 글자만 추려 써야 합니다.
- 생성 스크립트가 리눅스 글꼴 경로를 쓰기 때문에 윈도우에서는 경로를 바꿔야 빌드됩니다.

## 다시 만들기

```bash
pip install fonttools brotli pillow uharfbuzz
python 도구/release.py <개발폰트 폴더>
python 도구/verify.py
```

`release.py`는 원본을 읽어 이 폴더에 패키지와 zip을 다시 만듭니다. README만 고쳤으면 `python 도구/release.py --zip`으로 zip만 다시 묶습니다.
