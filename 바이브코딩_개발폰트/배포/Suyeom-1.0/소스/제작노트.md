# 수염체 (Suyeom) 폰트 프로젝트

장식용 한글 디스플레이 폰트입니다. Noto Sans CJK KR Black 글리프를 바탕으로, 스크립트가 수염 장식을 자동으로 덧붙여 생성합니다.
제목·로고처럼 큰 크기로 쓰는 용도이며, 본문용이 아닙니다.

## 스타일 두 벌

| 파일 | 한글 이름 | 영문 이름 | 모음 위 장식 |
|---|---|---|---|
| SuyeomBrush-Regular | 수염체 붓털 | Suyeom Brush | 붓털이 부채꼴로 퍼지는 장식 |
| SuyeomMustache-Regular | 수염체 콧수염 | Suyeom Mustache | 끝이 말려 올라간 콧수염 |

두 벌에 공통으로 적용되는 규칙:
- **규칙 1 – 모음 위 장식**
  - 세로 모음(ㅏ·ㅐ·ㅘ 등)이 있는 글자는 세로획 맨 위에 장식을 답니다.
  - 가로 모음(ㅗ·ㅜ·ㅡ)만 있는 글자는 글자 맨 위 가운데에 답니다.
- **규칙 2 – 막힌 공간 채우기**: ㅇ·ㅁ·ㅂ·ㅍ·ㅎ 등의 막힌 공간을, 중심을 향해 모이는 방사형 수염으로 채웁니다.
- **낱자모(U+3131–3163)**: 획 끝에 붓털을 답니다(`JAMO_ENDS` 표 참고). 모음 낱자도 규칙 1을 따릅니다.
- **영문·숫자·기호**: 원본 글리프를 그대로 씁니다.

## 수록 범위

- 한글은 KS X 1001 완성형 2,350자(EUC-KR 0xB0A1–0xC8FE)를 넣었습니다.
- 그 밖에 호환 자모, ASCII, 기본 기호를 넣었습니다.
- 총 2,533 글리프입니다.
- 완성형에 없는 글자(뷁·똠 등)는 빈칸으로 나옵니다.
- 11,172자 전체로 넓히려면 `build.py`의 `ksx1001()` 대신 `range(0xAC00, 0xD7A4)`를 쓰면 됩니다. 생성 시간과 용량은 약 4.7배로 늘어납니다.

## 파일 구성

```
build.py      폰트 생성기 (스타일 1벌 = 1회 실행)
preview.py    테스트 렌더링: python3 preview.py <font> <out.png> "줄1" "줄2" ...
out/          배포본 — OTF, WOFF2, OFL.txt, specimen.png, build.py 사본
```

## 빌드

```bash
pip install --break-system-packages fonttools skia-pathops brotli pillow
python3 build.py brush    out/SuyeomBrush-Regular.otf      # 약 40초
python3 build.py mustache out/SuyeomMustache-Regular.otf   # 약 30초
# 일부 글자만 빠르게 시험: 세 번째 인자로 글자 목록
python3 build.py brush test_b.otf "ㅏㅑ소요강호선생님ㅇㅂ"
# WOFF2 변환
python3 -c "from fontTools.ttLib import TTFont as T; f=T('out/SuyeomBrush-Regular.otf'); f.flavor='woff2'; f.save('out/SuyeomBrush-Regular.woff2')"
```

- 원본 폰트 경로는 `SRC = /usr/share/fonts/opentype/noto/NotoSansCJK-Black.ttc`이고, 이 컬렉션의 index 1(KR)을 씁니다.
- 다른 환경에서 빌드할 때는 `SRC`를 `NotoSansCJKkr-Black.otf` 경로로 바꾸고, `TTCollection(...).fonts[1]`을 `TTFont(...)`로 바꿉니다.

## 조정 포인트 (build.py)

| 바꾸고 싶은 것 | 위치 |
|---|---|
| 한글 축소 비율(장식이 들어갈 위쪽 여백) | `SX, SY, YBASE, XC` |
| 붓털 길이·퍼짐·가닥 수 | `fan(length=190, spread=1.35, count=19)`, `build_hangul`의 `L = 190 / 165` |
| 가로 모음 글자의 붓털 폭 | `build_hangul`의 `m ± 45` |
| 콧수염 크기 | `build_hangul`의 `mustache(..., w)` — 세로 `max(340, 폭+230)`, 가로 `360` |
| 콧수염 모양 | `mustache()`의 `ctrl` 좌표(반쪽 외곽선, Chaikin 3회 다듬기) |
| 막힌 공간 수염 밀도·가운데 흰 구멍 | `burst()`의 `n`, `tip_gap`, `width` |
| 낱자모 획 끝 붓털 위치 | `JAMO_ENDS` |

## 구조 메모

- 처리 흐름은 다음과 같습니다.
  1. 원본 글리프를 skia-pathops로 union합니다.
  2. 윤곽을 꺾은선으로 펼친 뒤 면적 부호로 바깥 윤곽(ink)과 구멍(hole)을 나눕니다.
  3. 장식 경로를 더해 다시 union합니다.
  4. T2CharStringPen으로 CFF를 생성합니다.
- 장식의 무작위성은 글자 코드로 시드를 고정한 `random.Random`을 씁니다. 그래서 다시 빌드해도 결과가 같습니다.
- `centroid()`는 부호 있는 면적으로 계산합니다. 예전에 부호를 잘못 처리해 중심점이 음수로 나오던 버그가 있었습니다.
- `top_clusters()`는 점이 아니라 "윗변 위의 선분"을 모으는 방식입니다. 점만 모으면 직사각형 획의 윗변을 놓칩니다.
- 장식이 위로 튀어나오므로 `hhea ascent`는 1050, `usWinAscent`는 1050으로 잡았습니다. 콧수염형의 최대 y는 약 958입니다.

## 라이선스 (꼭 지킬 것)

- 원본 Noto Sans CJK는 SIL OFL 1.1이므로, 파생물인 이 폰트도 OFL 1.1을 따릅니다.
- 배포할 때는 `OFL.txt`를 반드시 함께 넣어야 합니다.
- 폰트 단독 판매는 금지입니다. 폰트를 포함한 디자인물·소프트웨어의 판매나 상업적 사용은 가능합니다.
- 폰트 이름에 예약 이름 "Source"를 쓰면 안 됩니다.
- name 테이블의 copyright·license 항목은 `build()` 안에서 설정합니다.
