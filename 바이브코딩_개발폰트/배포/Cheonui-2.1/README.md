# 천의체 2.1 사용 안내

십이지신도의 구름(운문)과 천의(옷자락)를 장식으로 담은 한글 제목용 서체입니다. 바탕 글자는 본명조(Noto Serif KR)이며 한글 11,172자를 모두 지원합니다.

## 글꼴 두 가지

| 글꼴 | 파일 | 장식이 붙는 방식 | 쓰는 곳 |
|---|---|---|---|
| **천의체** (Cheonui) | `Cheonui-Regular/Bold` | 단어 첫 글자에 **자동** (OpenType `calt`) | 웹, 브라우저 기반 툴 |
| **천의체 장식** (Cheonui Deco) | `CheonuiDeco-Regular/Bold` | **모든 글자에 구름이 미리 붙어 있음** | 워드, 한글(HWP), 포토샵 등 자동 장식이 안 되는 프로그램 |

천의체 장식은 장식할 글자만 골라 글꼴을 바꾸는 방식입니다. 예를 들어 "병오년 새해 복"에서 `병`, `새`, `복`만 천의체 장식으로 바꾸면 됩니다.

## 프로그램별 사용법 (2026-11-08 확인)

| 프로그램 | 결과 | 권장 사용법 |
|---|---|---|
| 크롬 (웹) | ✅ 자동 장식, 컬러, 스타일 세트 모두 동작 | 천의체를 그대로 사용 |
| 워드 2016 | 자동 장식 ❌, 장식 문자 ❌ (PDF에서 사라짐), **천의체 장식 ✅** (PDF에서는 단색) | 장식할 글자만 '천의체 장식'으로 변경 |
| 포토샵 2022 | 자동 장식 ❌ (기본 설정), 장식 문자 ✅ 단색 | 천의체 장식 사용, 또는 장식 문자 직접 입력 |
| 일러스트레이터, 피그마 | 확인하지 못함 | 아래 '직접 확인'으로 점검 |

2.1에는 어도비 앱이 읽는 SVG 컬러를 장식 문자(U+E000~E017)에 추가했습니다. 포토샵·일러스트레이터에서 컬러로 나오는지는 아직 확인하지 못했습니다.

## 웹에서 쓰기

| 기능 | 효과 | 추천 용도 |
|---|---|---|
| 기본 | 단어 첫 글자에 구름 | 제목, 포스터, 연하장 |
| `ss01` | 모든 글자에 구름 (구름 띠) | 2~6자 로고, 테두리 장식 |
| `ss02` | 구름 대신 천의 리본 | 강한 인상의 타이틀 |
| `ss03` | 장식 없음 | 본문, 캡션 |

```css
@font-face { font-family: "Cheonui"; font-weight: 400; src: url("Cheonui-Regular.woff2") format("woff2"); }
@font-face { font-family: "Cheonui"; font-weight: 700; src: url("Cheonui-Bold.woff2") format("woff2"); }
@font-face { font-family: "Cheonui Deco"; font-weight: 700; src: url("CheonuiDeco-Bold.woff2") format("woff2"); }
@font-palette-values --gold { font-family: "Cheonui", "Cheonui Deco"; base-palette: 2; }

h1 { font-family: "Cheonui"; font-weight: 700; line-height: 1.5; }   /* 첫 글자 구름 */
.logo { font-feature-settings: "ss01"; }                              /* 모든 글자 */
p { font-family: "Cheonui"; font-feature-settings: "ss03"; }          /* 본문 */
.gold { font-palette: --gold; }                                       /* 금박 */
```

**주의:** 웹에서 천의체 장식과 천의체를 한 줄에 섞으면, 장식 글자 바로 뒤 글자에도 자동 장식이 붙어 구름이 겹칩니다. 섞어 쓸 때는 그 줄에 `ss03`을 켜세요.

```html
<h1 style="font-feature-settings:'ss03'"><span class="deco">병</span>오년 <span class="deco">새</span>해</h1>
```

색 팔레트 3종: 0 오방색(기본), 1 단청, 2 금박. 장식의 먹선은 글자색을 따릅니다.

## 장식 문자 직접 넣기

폭이 0인 장식 문자입니다. 장식을 넣을 글자 **바로 앞**에 입력하세요 (윈도우 문자표 → 고급 보기 → 유니코드 사용자 정의 영역). 포토샵에서는 동작하지만 워드에서는 출력되지 않습니다.

- 구름 8종: U+E000 ~ U+E007
- 천의 리본 8종: U+E010 ~ U+E017

## 직접 확인 (포토샵·일러스트레이터)

1. 폰트 4개(`.ttf`)를 설치합니다.
2. 포토샵: 파일 → 스크립트 → 찾아보기 → `포토샵_확인.jsx`를 선택합니다. 새 문서에 시험 문구 3줄이 만들어집니다.
3. 1번 줄의 구름이 컬러면 SVG 컬러가 지원되는 것이고, 2번 줄에 단색 구름이 보이면 천의체 장식이 정상입니다.
4. 3번 줄을 선택하고 문자 패널 → OpenType → '문맥에 따른 대체'를 켜면 자동 장식이 붙는지 확인할 수 있습니다.

## 사용 팁

- 장식이 글자 위로 올라가므로 제목의 줄 간격은 **1.4 이상**을 권장합니다.
- 인쇄용 파일은 글자를 윤곽선으로 만들거나 이미지로 넣는 것이 안전합니다.
